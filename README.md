# 법인등기 열람 자동신청 (웹)

## 설치 (최초 1회)
    pip install -r requirements.txt
    playwright install chromium

## 실행
    python app.py          # 브라우저가 http://127.0.0.1:5000 로 자동으로 열립니다

## 사용 순서
1. 엑셀 첨부 (회사명 + 대표자/이름 열). 이미 `_등록번호.xlsx`인 파일도 가능(확정 행은 재조회 안 함)
2. API 키 입력(또는 환경변수 DATA_GO_KR_KEY / key.txt) → [시작]
3. 조회가 도는 동안 자동으로 열린 인터넷등기소 창에서 로그인 → 웹의 [로그인 완료]
4. 신청 담기가 끝나면 열린 창에서 직접 결제 → 웹의 [종료]

처음에는 엑셀을 2~3행만 남겨 시험해 보세요.
결과는 output/<작업ID>/…_결과.xlsx 에 저장되고 화면에서 받을 수 있습니다.
